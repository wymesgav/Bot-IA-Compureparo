Compureparo · WhatsApp Bot

Cómo se conecta y funciona el bot

Un mensaje de WhatsApp cruza tres sistemas antes de volver como respuesta: Meta, una función Lambda sin servidor, y un modelo Claude en Amazon Bedrock. Este documento traza esa ruta y el camino separado por el que llega el código: de tu máquina a la imagen que Lambda ejecuta.

03 Piezas de configuración

Variables de entorno (Lambda)

WHATSAPP_TOKEN
token de acceso del Graph API
WHATSAPP_VERIFY_TOKEN
string propio, valida el webhook
WHATSAPP_PHONE_NUMBER_ID
identifica el número emisor
BEDROCK_MODEL_ID
us.anthropic.claude-haiku-4-5⁠-⁠20251001-v1:0
BEDROCK_REGION
us-east-1

Permisos del rol de ejecución

  • AWSLambdaBasicExecutionRole — escribe logs en CloudWatch
  • BedrockInvokeClaudeHaiku — bedrock:InvokeModel, acotado al perfil de inferencia y al modelo base, nada más
  • Sin acceso a otros servicios de la cuenta
