Política de Privacidad — Compureparo Bot

Última actualización: 22 de septiembre de 2026

Compureparo (soporte técnico de computadores, redes y cámaras de seguridad, atendido por Wilmar Mesa en Medellín, Colombia) opera un asistente automático de WhatsApp ("el bot") para responder preguntas de precios y ayudar a agendar visitas técnicas. Esta página explica qué información procesa el bot y cómo la usa.

Qué información se procesa

  • El número de teléfono de WhatsApp desde el que escribes.
  • El contenido de texto de los mensajes que le envías al bot.

No se solicita ni se procesa ningún otro dato personal (no se piden documentos de identidad, datos financieros ni ubicación exacta).

Para qué se usa

Únicamente para generar una respuesta automática sobre precios de servicios, planes de mantenimiento, o para coordinar el agendamiento de una visita técnica. El mensaje se envía a Amazon Bedrock (modelo Claude, de Anthropic) para generar la respuesta, y la respuesta se reenvía a tu conversación de WhatsApp a través de la API de Meta.

Almacenamiento

El bot no guarda tus mensajes en una base de datos permanente. Cada mensaje se procesa en el momento para generar una respuesta y no queda un historial accesible más allá de lo que WhatsApp conserva de forma nativa en tu propia conversación.

Con quién se comparte

La información solo pasa por los proveedores de infraestructura necesarios para que el servicio funcione:

  • Meta — como operador de la API de WhatsApp Business, por donde llegan y salen los mensajes.
  • Amazon Web Services (Amazon Bedrock) — para generar el texto de la respuesta.

No se vende ni se comparte información con terceros para fines de publicidad o marketing.

Tus opciones

Puedes dejar de escribirle al bot en cualquier momento. Si quieres que se elimine cualquier registro asociado a tu número, o tienes preguntas sobre este tratamiento de datos, escribe directamente a Wilmar Mesa:
